Quand ça coince

Dépannage

Presque tout se règle avec deux réflexes : le nœud tourne-t-il, et la clé est-elle la bonne. Commencez par là.

Le premier outil : memcp doctor

Il vérifie le dossier de données, les droits des fichiers, les connexions, les pairs et ce qui attend. Sa sortie dit quoi corriger, sans jargon. Dans l'application Home Assistant, lancez-le dans le conteneur ; ailleurs, dans un terminal.

Le nœud ne répond pas

  • Sur Home Assistant : l'application est-elle démarrée ? Les journaux sont dans son onglet Journal.
  • Sur Linux : systemctl --user status memcp, puis le journal du service.
  • Sur un Mac : l'app doit être ouverte, ou le service lancé. Une fenêtre fermée ne suffit pas à arrêter le nœud, l'icône de la barre des menus dit s'il tourne.

L'assistant reçoit « clé refusée »

Code 3 côté commande : la clé est inconnue, révoquée ou expirée. Code 4 : la clé est bonne, mais elle n'a pas le droit demandé. Dans les deux cas, ouvrez la page, regardez les connexions, et donnez à l'assistant une clé neuve avec les bons espaces. Une clé ne se réaffiche jamais : si vous ne l'avez plus, révoquez la connexion et créez-en une autre.

L'assistant ne voit pas un espace

Un espace doit être coché sur la connexion. Et les droits ne descendent pas : si vous avez coché Perso, l'assistant ne lit pas Perso/Santé pour autant. C'est voulu.

Une note reste dans l'Inbox

Deux raisons s'affichent à côté d'elle : aucun mot-clé ne correspond, ou deux espaces se disputent la note. Ouvrez l'espace concerné, ajoutez le mot qui manque dans ses mots-clés, ou envoyez la note d'un geste. La fois suivante, elle ira toute seule.

Un enregistrement n'est pas transcrit

La transcription est une option du nœud : vérifiez qu'elle est active et que le modèle répond. Un enregistrement qui échoue trois fois porte une marque et reste visible ; la page propose de réessayer. L'audio n'est effacé qu'une semaine après que son texte a été rangé.

Deux machines ne se parlent plus

Elles doivent se joindre : même réseau, ou même tailnet. memcp peers liste les pairs connus et leur dernière nouvelle. Un pair absent se réveille au prochain contact ; rien n'est perdu, la mémoire attend.
