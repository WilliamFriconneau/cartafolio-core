Installation

Sur Home Assistant

C'est le chemin le plus court si votre maison tourne déjà sous Home Assistant : le nœud devient une application, il démarre avec la maison, et la page Mémoire s'ouvre depuis la barre latérale.

Ajouter le dépôt

  1. Ouvrez Réglages, puis Applications (dans les anciennes versions : Modules complémentaires), puis la boutique.
  2. Menu ⋮, Dépôts.
  3. Collez https://github.com/WilliamFriconneau/cartafolio-core et validez.

Le lien direct fait les trois étapes d'un coup : ajouter le dépôt.

Installer et démarrer

Le dépôt apparaît dans la boutique. Installez Cartafolio, puis démarrez. La première ouverture de la page depuis un compte Home Assistant fait de ce compte l'administrateur, et lui donne sa mémoire.

Chaque personne de votre Home Assistant qui ouvre la page Mémoire a la sienne : les espaces d'un compte ne sont pas visibles depuis un autre.

Les deux options qui changent la vie

OptionCe qu'elle fait
janitorLe rangeur : une fois par jour, et à l'arrivée des notes, il envoie dans le bon espace ce qui attend dans l'Inbox, en lisant les mots-clés de chaque espace. Il peut aussi demander un titre et des mots-clés à un modèle local ou à une API.
transcribeLa transcription des enregistrements : le texte est écrit à côté de l'audio, l'audio est effacé une semaine après. Un modèle Whisper sur le réseau, ou un service que vous choisissez.

Les deux sont désactivées au départ. Vous pouvez les activer plus tard, sans rien réinstaller.

Le port 8791 n'est pas chiffré

Sur ce port passent le MCP et l'OAuth. Les jetons y voyagent en clair. Ne l'ouvrez pas sur Internet tel quel : mettez Tailscale devant, ou un proxy TLS. La marche à suivre est dans docs/TAILSCALE.md.

Mettre à jour

Une nouvelle version sort comme les autres applications de Home Assistant : la boutique la propose, vous cliquez. La mémoire n'est pas touchée. Une sauvegarde se fait application arrêtée, ce qui garantit une copie cohérente des bases.

Vous pouvez aussi vérifier que tout va bien : memcp doctor vérifie le dossier de données, les droits, les connexions et les pairs. Il est disponible dans le conteneur de l'application.
