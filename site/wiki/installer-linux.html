Installation

Sur Linux

Une commande, un dossier de données, une page. Le programme est un binaire : pas de conteneur obligatoire, pas de base à préparer.

Le script

curl -fsSL https://raw.githubusercontent.com/WilliamFriconneau/memcp-core/main/install.sh | sh

Il demande où doit vivre la mémoire, télécharge le binaire, vérifie son empreinte contre le fichier SHA256SUMS publié avec la version, puis lance memcp setup : un dossier privé, vos premiers espaces, un fichier memcp.toml.

Il peut ensuite lancer le nœud comme service de votre compte, qui n'écoute que la boucle locale, et il affiche deux choses à garder : l'adresse de la page, et une adresse avec une clé pour un assistant.

Lisez le script avant de le lancer, c'est un fichier texte. --help liste les options.

Ce que vous obtenez

QuoiOù
Les donnéesUn dossier de votre choix, lisible par votre compte seulement.
La pagehttp://127.0.0.1:8791 sur la machine, ou l'adresse de votre tailnet.
Le serviceUne unité systemd de votre utilisateur, ou un conteneur si vous préférez.

Le service, la sauvegarde, le TLS

docs/LINUX.md donne les unités systemd durcies, les paquets Debian et Arch, une sauvegarde nocturne, les règles de pare-feu et deux recettes TLS. C'est le document à suivre si la machine est un vrai serveur.

La sauvegarde tient en une commande : memcp export --to /chemin/du/sauvegardes. Elle produit une archive avec les empreintes, qu'une autre installation sait reprendre.

Mettre à jour

Relancez le script d'installation : il remplace le binaire, garde le dossier de données. Le journal des versions est dans CHANGELOG.md.

Une machine suffit pour commencer. Si vous en avez deux, la seconde rejoint la mémoire et en garde une copie : voir vos autres machines.
